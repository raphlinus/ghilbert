# Ghilbert 2005-2007

A snapshot of the Python prototype from
[levien.com/garden/ghilbert](https://levien.com/garden/ghilbert/), which
predates the rest of this repo. It contains the verifier (`gh_verify.py`), a
Metamath translator (`mm_xlat.py`), typesetting and fonts, and the `hol`,
`pax`, `peano`, and `zfc` theories. The `zfc/set_mm*` files are translated from
set.mm.

The work was kept in darcs, with 74 patches by Raph Levien and Marnix Klooster
from October 2005 to July 2007. That history is not imported here; it remains
at the URL above under `_darcs`.
